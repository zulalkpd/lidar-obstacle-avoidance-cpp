# Otonom Engel Algılama ve Sensör Entegrasyon Sistemi

Bu proje; robotik platformlar için C++ tabanlı mesafe sensörü analizi, karar alma algoritması simülasyonu ve Fusion 360 ile modellenen 3D baskıya uygun donanım montaj braketini içerir.

# Özellikler:
- **C++ Karar Algoritması:** Ön, sağ ve sol açı taramalarıyla güvenli rota tayini.
- **Donanım Entegrasyonu:** Sensörün sarsıntısız çalışması ve kablo geçişi için özel tasarlanmış 3D montaj aparatı (`.stl`).
